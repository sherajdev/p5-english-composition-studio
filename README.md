# P5 English Composition Studio

An interactive, single-file website that helps a Primary 5 student prepare for English composition (Paper 1, Part 2 Continuous Writing).

## Features
- 11 Primary 5 English SA2 2025 exam papers organised by composition topic, with the picture prompts
- Filters by theme (Responsibility, Lessons, Effort & growth) and by picture clue
- Story mountain tips for every paper, with a walkthrough and sample sentences
- "Think before you write" questions, each with a hideable example answer
- Story planner, model stories, 10-minute picture practice timer
- Writing tips, vocabulary list and a hand-in checklist
- Mobile friendly, pastel paper-art style, no build step

## Use
Open `index.html` in a browser. It is fully self-contained (fonts load from Google Fonts when online).

## Notes
Picture prompts are cropped from publicly shared school exam papers and remain the property of their schools. Remove them if you reuse the code elsewhere.
